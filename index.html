Data Engineering

Retail Data Pipeline & ETL

Pentaho Data Integration · MySQL · Power BI · 2026

Context

A retail store extract of 12,575 transactions arrived as raw, inconsistent records that no one could query or read. The task was to turn it into something a non-technical audience could open and trust.

Approach

  1. Ingest — Pentaho Data Integration reads the raw extract.
  2. Clean — 604 records dropped for missing or invalid fields, leaving 11,971 valid rows.
  3. Model — a star schema: 1 fact table and 5 dimensions.
  4. Present — a Power BI dashboard built on the modelled tables.

Result

Total Revenue
$1.55M
Valid Transactions
11.97K
Avg/Transaction
$129.77
Total Units
66K

Every revenue figure in the dashboard traces back to the single fact table, so the numbers can be audited rather than re-derived.

Data Analytics

Cafe Sales Analytics

Python · pandas · scikit-learn · 2026

Context

9,227 cafe sales records across 12 variables, of uneven quality. The question was what actually drives daily sales, and whether that could be forecast from the history alone.

Approach

  1. Profile and clean — a data-quality pass over all 12 variables before any analysis.
  2. Explore — revenue by product, daily unit volume, and a monthly rolling trend.
  3. Segment — days and stores separated into high, medium and low production tiers.
  4. Forecast — a Random Forest Regressor on the engineered time features, scored with MAPE.

Result

Dataset Size
9,227
Forecast Error
18% MAPE
Variables
12
Model
Random Forest

Sandwiches and smoothies carried revenue, daily volume sat around 1,300 units, and the tier segmentation showed which stores could absorb more production.
